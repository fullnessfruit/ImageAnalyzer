# 샘플 정답

[`labels.json`](labels.json)은 `sample/` 이미지의 파일별 정답이다. `people`과 `characters`는 이미지에 보인다고 확인한 대상이며, 이름의 중복 없이 한 이미지에 묶었다. `subjectNotes`는 뒷모습, 옆얼굴, 이미지 내 위치처럼 대상별로 필요한 설명이다. 이 기록은 모델의 현재 출력이 아니다.

`ocr`는 실제로 적혀 있고 회귀 검사에서 찾아야 하는 검색어다. `optionalOcr`는 적혀 있지만 현행 인식 실패를 허용한다. `ocrText`는 검색어와 다른 실제 표기 또는 줄 배치를 설명한다. `faceChecks`는 기존 얼굴 회귀 검사의 필수 성공 대상이며, `people`에 기록된 모든 사람이 곧바로 얼굴 검사의 필수 성공 대상이 되는 것은 아니다. 얼굴이 거의 보이지 않는 신체 판정 시험 이미지는 `faceCheck: "skip"`이다. 캐릭터 라벨도 실제 등장 여부를 기록하며, 현재 검사기는 누락을 진단 출력으로 남긴다.

일곱 이미지의 `absent: "allCatalogedSubjects"`는 `subjectCatalog.people`과 `subjectCatalog.characters`에 **이름이 전부 적힌 대상 모두**가 그 이미지에 없다는 뜻이다. 목록에는 QMa 이미지에서 OCR 텍스트로만 라벨링한 相良茉優·内田秀도 포함한다. 다른 미등록 인물·캐릭터나 텍스트까지 없다는 뜻은 아니다. `unlabeledImages`는 파일은 있으나 확인된 정답이 없는 이미지다. 이를 음성 샘플로 사용하면 안 된다.

`trainingMedia`의 세 경로는 `sample/` 밖의 上原歩夢 갤러리 원본이다. 각각 인형 사진, 굿즈의 데포르메 일러스트, 피규어 사진이라는 매체 차이를 남겼다. 나머지 갤러리 원본까지 이 샘플 파일의 정답으로 간주하지 않는다.

`npm run samples:labels`는 이름 참조와 실제 이미지 목록을 검사한다. `npm run samples:labeled -- <파일명>`은 지정한 이미지의 분석 결과를 기록된 얼굴·OCR 정답과 비교한다. 매체와 뒷모습 라벨은 존재 정보이지 현재 모델의 성공 보증이 아니다.
